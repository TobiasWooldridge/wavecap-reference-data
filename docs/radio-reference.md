# Radio reference provenance and precedence

[SA Scan original](https://www.sascan.net.au/?page=infPages/GRNTalkgroups) and
[requested archive](https://web.archive.org/web/20251225115143/https://www.sascan.net.au/?page=infPages/GRNTalkgroups)
were fetched with two bounded ordinary requests (rendered archive and raw variant).
Both returned200 and Memento datetime2025-12-25T11:51:43Z, matching the requested
capture. The page's own update date is2025-07-27; neither date means current2026
allocation. Raw HTML is retained outside git; its hash is in the provenance.

The factual table yields678 distinct decimal P25 talkgroup IDs. The ID cell is
separate from human channel prefixes: ID3157 is hexC55; the leading001 in its
label is a channel number, not talkgroup1. Parenthesized legacy numbers in labels
are not reinterpreted as current IDs. Eight empty/unknown ID cells are rejected.
Four IDs have multiple source labels (155,159,1543,2671): variants/categories
remain and selected name isnull. No arbitrary winner is chosen.

Comparison with the existing configured ID keys found444 matches and234 new IDs.
Different spelling/formatting is reported as different labels, not automatically
as semantic error. Existing RR-derived names are not republished in the comparison;
only IDs/counts/config digest are retained. This import does not overwrite an
application's configured or operator-verified names. Reference seeds have lower
precedence and must be joined by exact configured network/source plus TGID.

No explicit source reuse licence was found in the retained page. Original
contributions/arrangement are offered under CC BY-SA4.0; this does not assert an
upstream licence grant. Only independently structured factual IDs and short
labels/categories are included, with both citations. No page narrative/layout,
raw HTML, artwork, feed, audio or incident content is republished.

The six radio/unit records are separately curated explicit operator confirmations,
not SA Scan allocations. Public confirmation URLs do not exist and remainnull.
Three records retain supplied effective timestamps; three older timeless entries
have unknown bounds and retain the2026-10-11 confirmation date. Null expiry does
not prove permanent assignment. All records are scoped to configured source
`sagrn`; WACN/system identifiers were not supplied and are not invented. Adelaide
Fire station role and the older three appliance types remain unconfirmed. The
reviewed/inferred console family and its private evidence were excluded.

Consumer policy: verified/operator assignment first, existing curated overrides
next, unambiguous historical reference seed last. Do not derive neighbouring
radio IDs, transfer identities across sources, or make a compact display label
the canonical identity. Keep the source/confirmation citation visible where used.
